# LeEco Smart Remote — Neo Light Edition

Professional light neo-morphic Android remote for LeEco/Android TV devices.

## Included
- Light neo-morphic UI with raised/inset controls
- Remote, Touch, Apps, Macros and Settings sections
- D-pad, Home, Back, Menu, Info, Guide
- Volume/channel/media controls
- Number pad
- Voice search and text input
- Quick app launch
- Custom package launcher
- One-tap scenes/macros
- Wireless ADB pairing and connection
- Saved TV IP and port

## Important
This project does not bypass Android security. The TV must already expose ADB over network / wireless debugging, and the phone and TV normally need to be on the same network.

Open the project in Android Studio, sync Gradle, then build the debug APK.
