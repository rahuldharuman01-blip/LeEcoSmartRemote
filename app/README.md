# LeEco Smart Remote — Liquid Glass Edition

A polished liquid-glass Android remote for LeEco / Android TV devices, built from the existing LeEco Smart Remote project.

## UI refresh
- Liquid-glass style translucent controls with glossy highlights, soft outlines, rounded corners and pastel blue/cyan accents.
- High-contrast, darker text for readability.
- Glass-style connection/status cards and inset input fields.
- Credit footer: **Designed & Developed by Rahul Dharuman**.
- SmartTube quick launch replaces YouTube for this TV setup.

## Features
- Remote, Touch, Apps, Macros, Settings and TV Update sections.
- Power, mute, home, D-pad, back, menu, info, guide, volume, channel and media controls.
- Number pad, voice search and text input.
- SmartTube, Netflix, Prime Video, JioHotstar and Android Settings shortcuts.
- Wireless ADB pairing/connection and saved TV IP/port.
- TV firmware information and official system-update settings shortcut.

## Build
Open this folder in Android Studio, sync Gradle, and build the debug APK. The project retains application ID `com.rahul.leecoremote`.

## Connection note
The phone and TV must be on the same network and the TV must already expose ADB over network / wireless debugging. The app does not bypass Android security or force-flash TV firmware.
